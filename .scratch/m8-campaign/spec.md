Status: open
Created: 2026-09-25
Roadmap: `.scratch/v1/map.md`

## Goal

Five missions that double as the tutorial (spec: Game modes).

1. Survive the first winter.
2. Invite your first master.
3. Clear the den in the old forest.
4. Pay the crown's tribute.
5. Earn the town charter.

Done when all five can be played in order from the main menu, each teaches its systems, and each can be won or failed.
