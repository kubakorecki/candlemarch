# Code map

Orientation for agents. Read before exploring; update when a module is added, moved or renamed.

## content (`packages/content/src`): typed data, no logic
- `types.ts`: every ID union (`ResourceId`, `BuildingId`, `JobId`, `RecipeId`, `TerrainId`, `MapObjectId`, `RoadId`, `HeroId`, `SeasonId`, `PoiId`) and def shape (`BuildingDef`, `RecipeDef`, `JobDef`, `CalendarDef`, `NeedsDef`...), plus the `Content` aggregate.
- `index.ts`: assembles and exports `content: Content`; re-exports all types.
- `resources.ts` (`GoodsDef` on stockpiles | `FoodDef` in a Granary with `spoilPercent`; `meat` is Food, `hides` pile up on Stockpiles; `stone`, `clay`, `iron_ore` come from Deposits, nothing makes them yet), `recipes.ts`, `buildings.ts` (size, door, employs, `gathers` list + `workRadius`, `digs` (map objects its workers dig out once marked: the woodcutter's hut digs `stump`, whose gather numbers are the dig), `hunts` (hunt ticks, catch), `outputBuffer` (`resources` it makes + `yard`, the tile beside the door they pile on, an offset outside `size`), input buffers, recipes, `residents` (makes it a House), `foodCapacity` (makes it a Granary), `light` (`LightDef`: radius, fuel, burn a night, holds; makes it a light: `torch`, `brazier`), `bell` (`BellDef`: `rangeTiles`; makes it the Militia bell), `watch` (`WatchDef`: `rangeTiles`, `damage`, `cooldownTicks`; makes it a watchtower, which employs a `watchman`), `wall` (`WallDef`: `hp`, `gate`; makes it a 1×1 wall segment, `palisade` or `gate`, whose door is its own tile), `onePerVillage`, `plants` (`PlantsDef`: `object`, `on` terrain, `spacing`, `plantTicks`; makes it a forester's lodge: `foresters_lodge` plants Saplings on Meadow, spacing 2, radius 6), `groundwork` (`GroundworkDef`: `on` terrain, `becomes` `{terrain}` or `{road}`; makes it a 1×1 groundwork site laid like a Road: `drain` (Swamp → Meadow, 2 logs, 200 ticks), `pass_road` (Pass snow → `pass_road` Road, 6 logs, 600 ticks)), construction cost), `jobs.ts` (walk speed, carry, idle retry; `watchman` works nights; `forester`), `mapObjects.ts` (tree, `walkSpeedPercent` 50: walked through; forage patches `berry_bush`, `mushroom_patch` with a `forage` def: stock per season, shade; Deposits `stone_deposit`, `clay_deposit`, `iron_deposit` with a `deposit` def (`DepositDef`: `terrain`, `edge` `riverbank`/`face`), placeholder amounts; `sapling` with a `grows` def (`GrowsDef`: `into`, `days` 20, `stages` 3): amount 0, walked over, nobody gathers it; `stump` grows the same way into a `sapling` in 20 days, 1 stage), `terrain.ts` (`meadow`, `rock`, `mountain`, `swamp`, `river`, `ford`, `pass_snow`: `walkable`, `buildable`, `speedPercent` (0 where not walkable), `heroSpeedPercent` (Pass snow: 30, the Hero alone wades it)), `roads.ts` (`dirt_path` 150%, `pass_road` 100%: only a finished Pass road site lays it), `heroes.ts` (aura), `logistics.ts` (stockpile tile capacity, `yardCapacity` 10), `calendar.ts` (dayTicks 3600, seasons, night length, riverFrozen, spoilPercent), `needs.ts` (Tired: min sleep %, speed %; Hungry: meal units, speed %, starve after; Cold: fuel, House buffer, burn per night, stock-up and cold seasons, speed %, freeze after), `hunting.ts` (`HuntingDef`: forest map object, max catch permille, health-word thresholds, `recoveryDays` 2, `emptySeasons` 2, `returningGame` 2), `immigration.ts` (`ImmigrationDef`: Meals a head, closed seasons), `alerts.ts` (`AlertsDef`: `lowFoodDays`), `dens.ts` (`DensDef`: Gloamlings `spawnsPerDusk` per season, `darkRingTiles`, `budding` band, distance and cap, `cleared` (cache goods, `calmTiles`, `calmDays`)), `valley.ts` (`ValleyDef`: every number of the generated Valley: `size` 128, `attempts`, rim, entry, Camp (`entryTiles`, start goods, carriers), `guarantees` near the Camp, river and Fords, Side valley and Pass, forest, swamp, rock, Deposit groups (`deposits`: `groups` per kind, `groupSize` 3–20, `linkTiles`, `touchPercent`, `spacingTiles`, `campOutcropTiles`), Den counts, points of interest (`pois`: `ruins` 2, `campTiles`, `clearTiles` (the stamp), `spacingTiles`, `shrineAlongPercent`), Hunting grounds (`maxTiles` 250, `minTiles`, `treesPerGame` 10, `names`); `IntRange`), `pois.ts` (`PoiDef` per `PoiId`: `ruins` with a `search` (`SearchDef`: `ticks` 200, `cache` 15 firewood and 6 hides, `spreadPercent` 30), `abandoned_mine` (a marker), `shrine` with `wardTiles` 12), `fog.ts` (`FogDef`: `startRevealTiles`, `sight` (`SightDef` day/night) for `hero`, `villager`, `building`, `mannedWatchtower`), `combat.ts` (`CombatDef`: a `FighterDef` (HP, damage, cooldown ticks, reach tiles) for `gloamling` (plus walk speed, sight), `villager` and `hero` (plus `knockoutTicks`) and `den` (its HP and sting); `houseDoorHp`), `villagerNames.ts`.

## sim (`packages/sim/src`): pure, deterministic
- `index.ts`: public API; the client and tooling import only from here. Export new helpers here.
- `state.ts`: `GameState`, `Components`, all component and task types, `STATE_VERSION`, `TICKS_PER_SECOND`, `TILE_UNITS` (1000), `DIAGONAL_UNITS`.
- `step.ts`: `step()`, the tick (see below); `stepInPlace()` runs the same tick without the copy, for runs that own their state (the sim worker, the balance harness, the benchmark). `commands.ts`: `Command` union + `applyCommand()` switch (`layGroundwork {building, from, to}` lays a Drain or a Pass road; `paintReserve`/`eraseReserve {from, to}` a Reserve rectangle (painting one takes Fell marks off its trees); `markTrees`/`markStumps`/`clearMarks {from, to}` the tree tools' marks).
- `entities.ts`: `createEntity` (bumps `mapVersion`), `destroyEntity` (clears every store; bumps `mapVersion` for an entity with a `tile`, `staticVersion` for a map object), `idsOf` (ascending IDs, no sort needed: JS lists integer keys in ascending order; use for any ordered loop).
- `mapCache.ts`: derived map data cached off each state object (a `WeakMap`, never in state) until `state.mapVersion` changes: `mapChanged(state)` (call after anything that changes what blocks walking, road speed or Light: tile entities added/removed, a site finished, a wall's HP to 0 or back, roads, lights lit/out), `cached(state, content, key, build)` (read-only values: `blocked`, `blockedGates`, `occupied`, `objectSpeed`, `speedPercent`, `walkGrid`, `gloamling*` grids, `lit`, `*Regions`), `cachedCosts` (lazy `CostSearch`es by grid and start tile, at most 64), `inheritMapCache` (`step` hands the cache to its copy). A test that edits walkability straight into state after the grid was used must call `mapChanged`.
- `snapshot.ts`: split snapshots (ADR-0004). `staticChanged(state)` bumps `state.staticVersion`: call it after any change to a static layer (terrain, a Road, a map object added/removed or its `amount`/`withered`), and only when something really changed; `layPath`/`removePath`, `destroyEntity`, woodcutting, foraging, the Hero's chop, `patchesSystem` and `refreshShade` call it. `StaticLayers` (`version`, `terrain`, `roads`, `mapObject`, `mapObjectTile`), `staticLayers(state)`, `movingPart(state)` (the state with those emptied and the map objects' tiles left out of `tile`; both shallow, sharing objects with the state), `joinSnapshot(moving, layers)`. Patches: `sentStaticLayers(state)` (a deep copy: what the client holds, kept by the worker), `staticPatch(sent, state)` → `StaticPatch` (`version`, `terrain`/`roads` whole or null, `mapObject`+`mapObjectTile` added or changed, `removed` IDs; brings `sent` up to date), `applyStaticPatch(layers, patch)` (unchanged layers stay the same objects). `revealed` (Fog) and `reserve` are static layers like the others, compared and sent whole (`null` when unchanged); `map.inSight` stays in the moving part. `groundTiles` (each Hunting ground's `tiles` by ID) likewise: the moving part's grounds have `tiles: []`, `joinSnapshot` puts them back. A new static layer needs a field in all four and in `movingPart`/`joinSnapshot`.
- `fog.ts`: Fog (ADR-0005). `TileBits` helpers `hasTile`, `setTile`, `clearTile`, `noTiles(map)`, `allTiles(map)`; `isRevealed(state, tile)` / `isInSight(state, tile)` (always true with `state.fog` off, false off the map; the client reads these), `allRevealed(state, tiles)` (the build rule: `canPlaceBuilding` (so `layWall` too), `canLayPath` and `canPlaceStockpile` call it), `setFog(state, on)` (the `setFog` command; off clears `inSight`, Revealed kept).
- `rng.ts`: mulberry32 over `state.rng`: `seedRng`, `nextU32`, `randomInt(state, n)`.
- `calendar.ts`: derived from `state.tick`, nothing stored: `calendarAt`, `isNight`, `isDawn`, `isDusk`, `dawnTick`, `duskTick`, `isRiverFrozen`.
- `map.ts`: `MapDef` (optional `entry` tile on the edge where Newcomers arrive → `state.map.entry`; optional `huntingGrounds`, rectangles or tile sets (`{name, tiles, maxGame}`, as the Valley generator gives them), turned into tile sets (`addHuntingGround`) and created last so they never shift other IDs; start goods: `buildings[].stock`, `stockpiles[].goods`, checked to fit), `MAP_LEGEND` (`.` Meadow, `:` Rock, `^` Mountain, `,` Swamp, `~` River, `_` Ford, `*` Pass snow, `T` tree, `b` berry bush, `m` mushroom patch, `s` stone Deposit (on Rock), `c` clay Deposit (on Meadow), `i` iron Deposit (on Mountain), `=` path, `D` Den, `R` Ruins, `S` Shrine (both on Meadow), `M` Abandoned mine (an iron Deposit on Mountain with the mine over it); `createInitialState` throws on a Deposit `depositFits` refuses), `createEmptyState`, `createInitialState(seed, map, content, monsterRate = 100, fog = false)` (creates map objects, Dens and points of interest row-major; places everything ignoring Fog, then `revealCamp` whatever `fog` is, then sets `state.fog` and works out the sight).
- `valley/`: the procedural Valley (spec, World and map). `generate.ts`: `generateValley(seed, content)` → `Valley` (a `MapDef` plus `layoutSeed`, `camp` (the Granary's origin), `sideValley` and `pass` tile indices; `createInitialState` takes it as it is): lays out, turns/mirrors (one of 8, from the PRNG), cuts Hunting grounds, checks the guarantees and counts (`valleyProblems`, internal; Deposit groups are worked out from the tiles by `depositGroups`: Deposits within `linkTiles`, chained; every Forage patch and Deposit beside a reached tile) and on a miss retries with a seed derived from the last (`nextU32`), up to `valley.attempts`; the Starting Camp stands within `CAMP_MARGIN` of the Granary. `layout.ts`: `layOutValley(rng, content)` → `Layout` (flat per-tile arrays: `terrain`, `object`, `den`, `poi`, `sideValley`, `forest`; `entry`, `camp`, `clear` square) in one orientation (entry west, river west–east north of the Camp, Side valley south-east), in this order: rim, Side-valley wall, river, Fords, entry gap and clear square, Swamp at slow bends, the Pass, Rock, unreachable ground → Mountain, forest and Forage patches (density by `woodTreePercent(depth, forest, clearing)`: full deep in a wood, thinning to its edge and past it to lone outliers, clearings from a second noise; the Camp's own wood thinning toward the Camp; trees scattered on the clear square off the Camp's yard, `camp.yardTiles` round the Granary), Deposit groups (`placeGroup`: grown from a drawn centre within `linkTiles` of the group, apart or (`touchPercent`) touching at most in pairs, never walling a walkable tile in, `spacingTiles` from earlier groups; the Camp's stone group on a Rock outcrop grown `campOutcropTiles` round the sure one, its clay group on the near bank, both wholly within `depositTiles`), points of interest (`placePois`: the Abandoned mine on an iron Deposit facing the Side valley with its Den at the mouth, Ruins on cleared 3×3 Meadow stamps in the main valley, the Shrine nearest a point along the entry → Pass line; `valleyProblems` checks counts, the mine's Den, reach and the Shrine's ward), `connect` (4-connected and through trees, which it never fells; clears a Forage patch only where there's no other way, so every open tile, patch and Deposit is reachable from the entry, first with the Pass shut, then open), unshaded patches dropped, Dens (the mine's counts as the Side valley's; none on a stamp or in the Shrine's ward); helpers `inRect`, `chebyshev`, `neighbours`, `neighbourTable` (cached per size), `flood`. `grounds.ts`: `forestStretches(n, tiles, maxTiles, minTiles)` (4-connected stretches halved across their longer side until ≤ `maxTiles`). `noise.ts`: `valueNoise(rng, size, cell)`.
- `newGame.ts`: `newGame(setup, content)` (`NewGameSetup` `{map, seed, monsterRate, fog}`, `map` a `NewGameMap`: `'valley'` generates one from the seed, else a hand-made map by name; the worker's `newGame` message runs it), `campCentre(state, content)` (where the camera starts, in tiles: the middle of the first Granary, else the map's middle).
- `maps/`: `camp` (the Starting Camp, Pinewood, Old Wood Hunting ground with forage patches, river on the south edge), `meadow` (milestone 0; tests rely on its IDs), `shortHaul`, `longHaul`, `branchingNetwork`, `nights` (a standing village west of a Mountain ridge with one gap, a Den past it; no Hero); `index.ts` has `maps`, `MapName` (hand-made maps; new games start on a generated Valley).
- `grid.ts`: tile maths (`tileIndex`, `tileAt`, `tileCenter`, `tileOfPoint`, `rectTiles`), `buildingLayout(def, origin, rotation)` → `BuildingLayout` (`origin` and turned `size` of the body, `tiles` (the body's, then the yard's), `door`, `yard` (a Workplace's, else null); the one place content `size`/`door`/yard are read), `entityLayout`, `footprint`, `doorTile`, `entityDoor`, `blockedGrid(state, content, gatesBlock = false)` (cached, read-only; a tree (`walkSpeedPercent`), a Sapling, a wall's site, a groundwork site and a battered-down wall block nobody, a built Gate only with `gatesBlock`; a Road over unwalkable terrain (a Pass road) opens it), `heroBlockedGrid` (the same with Pass snow open), `occupiedGrid` (`blockedGrid` plus trees: what building, paving and piling refuse), `objectSpeedGrid` (each tile's map-object walking speed, 0 for none), `isHeroWalkableTerrain` (the Hero's move orders), `palisadeTiles` (palisades built or not; no Road over them), `standingTiles`, `isRiverbank`, `tilesUnderCaches`, `fitsAt` (keeps the entry tile clear, off caches, and every footprint tile out of a Den's dark ring; a Gate may stand on a Road), `canPlaceBuilding` (refuses a second `onePerVillage` building, built or site; both take an optional `rotation`).
- `walls.ts`: Palisades and Gates: `fullHp(content, type)` (a wall's HP, a House's door (`combat.houseDoorHp`), else null; map start, construction, save backfill and Dawn use it), `isBrokenWall` (0 HP: blocks nobody until Dawn), `isWallType`, `isWall`, `canLayWall`/`layWall` (a site per tile of the Road's L, skipping tiles that already hold a wall; all or nothing through `canPlaceBuilding`).
- `pathfinding.ts`: A* `findPath`, `costSearch(grid, start)` → `CostSearch.costTo(tile)` (Dijkstra that stops once the tile asked for is settled and resumes for the next; exact), `regions(grid)` (4-connected open regions) + `canReach(grid, regions, start, goals)` (whether `findPath` would succeed, without searching), `tileDistance`; road-aware costs.
- `roads.ts`: `lShapeTiles`, `canLayPath` (buildable terrain only, not over a palisade or its site), `layPath`, `removePath` (Dirt paths only; a Pass road stays), walking speed: `speedPercentAt` (a Road's speed, else the terrain's), `heroSpeedPercentAt` (Pass snow off the road at its `heroSpeedPercent`), `speedPercentGrid(map, content, hero?)`, `maxSpeedPercent` (fastest road or terrain, for the A* heuristic).
- `stockpiles.ts`: place/remove, `isStockpileGood`, `stockpileTakes`, per-tile `amountOnTile`/`roomOnTile`/`takeFromTile`/`addToTile`.
- `villagers.ts`: `spawnVillager` (every field set, no Home), `drawVillagerName`, `assignJob` (sets job + workplace, resets task store for the job), `isAtWork(v)` (routine `work`, not `fighting`, not `militia`; work systems, dispatch and traffic use it).
- `workers.ts`: `maxWorkers`, `workersAt`, `vacantPositions`, `reassignTargets`, `unassignWorker`, `reassignWorker`, `setWorkerLimit`, `releaseWorkers` (a demolished Workplace's), `dropWork` (the unassign rule for work in hand, keeping the Job: goods to the Workplace, haul dropped, task back to idle, stop at next tile).
- `hero.ts`: `HeroOrder` (`move`, `gather`, `deliver`, `pickup` (a building, stockpile or cache), `attack`, `attackDen`, `search` (Ruins not yet Searched, refused at night; the task `search {ruins, ticksLeft}` counts down on its tile, ends at Dusk, and another order or a knockout ends it too, so the next starts over)), `heroSearch` (the Search under way for the client: ruins, tile, percent; null while walking), `heroOf`, `orderHero` (refused while Knocked out), `heroOrderAt` (what a right-click means; a Gloamling on the tile → `attack`, else a Den → `attackDen`, Ruins not yet Searched → `search` by day (at night just `move`), a cache → `pickup`; under Fog a Gloamling counts only In sight, and an unrevealed tile is just `move`), `heroSystem` (an `attack` order follows its Gloamling and stands once in reach; `attackDen` walks to the Den's tile and stands once in reach; both end when the target is gone).
- `aura.ts`: hero production aura: `workSpeedPercent`, `boostedWorkplaces` (none while the hero is Knocked out).
- `speed.ts`: the shared slowdown helper. `speedPercent(state, content, villager, workplace?)` = worst slowdown (Tired, Hungry, Cold) × aura at `workplace`; `workTicks(state, content, worker, workplace, ticks)` (apply to any work timer). Movement scales walking by `speedPercent` without a workplace.
- `granary.ts`: Granaries (Food in `building.stock`): `isFood`, `foodIds`, `isGranary`, `foodIn`, `granaryRoom`, `villageFood`, `baseSpoilPercent`, `eatingOrder` (fastest-spoiling first), `hasMeal`, `takeMeal`, `nearestGranaryWithMeal`.
- `groundwork.ts`: Drains and Pass roads: `groundworkOf(content, type)`, `canLayGroundwork`/`layGroundwork` (a site per tile of the L, skipping tiles already holding one or the Road it makes; every other tile must be Revealed, the groundwork's `on` terrain, with no Road, map object or footprint; all or nothing), `finishGroundwork` (construction calls it: destroys the site, writes the terrain or Road, `mapChanged` + `staticChanged`), `groundworkDropTiles` (where Carriers deliver: the site's tile, or on Pass snow the walkable tiles beside it, so a Pass road builds from the reachable end, tile by tile; dispatch keeps the chosen one in `Haul.toTile`).
- `deposits.ts`: Deposits: `isDeposit`, `depositFits(state, content, type, tile)` (on its `deposit.terrain`, at a riverbank or a face if its `edge` asks; true for other map objects; hand-made maps check it, the generator can too). Nothing works them yet; they block walking like trees and the Hero can't chop them (nor a Sapling: `isTree`; `heroOrderAt` walks the Hero onto a Sapling).
- `forest.ts`: Saplings and Stumps (map objects with a content `grows` def): `growsOf`, `isGrowing`, `plantSapling(state, content, tile)` (tests use it too), `leaveStump(id)` (a felled tree becomes a Stump in place, same ID: `mapChanged` + `staticChanged`), `grow` (at a Dawn: stage from the time gone, or past `growsAt` turn into `grows.into`; a tree: `mapChanged` + `refreshShade`; always `staticChanged` when something changed), `clearGrowth(tiles)` (placing a building (footprint and door), wall, groundwork, Stockpile or Dirt path destroys the Saplings and Stumps under it), the forester's rules: `canPlant(lodge, tile)` (in radius, `plants.on` terrain, x and y multiples of `spacing`, and off the cached `unplantable` grid: map objects, Roads, Stockpiles, footprints and doors of buildings and sites, Dens, caches, the entry; Fog ignored), `plantableTiles(lodge)` (row-major).
- `reserves.ts`: Reserves (`map.reserve`, `TileBits`, a static layer): `inReserve(tile)`, `reserveRect(a, b)` (the rectangle between two corners, row by row), `canPaintReserve(from, to)` (corners on the map, every tile Revealed; any terrain, anything on it), `paintReserve`/`eraseReserve` (the commands; erasing ignores Fog), `addToReserve(indices)` (ignores Fog: the way in for a generator; `staticChanged` when a tile is new), `reserveNear(type, origin, rotation)` (Reserve tiles in the work radius of a building that fells trees, for the placement preview). Only woodcutters read it; foresters plant in it, and it blocks no building. `fellsTrees(type)` (a building that fells trees: the woodcutter's hut).
- `marks.ts`: the tree tools' marks, a flag on the map object (`mapObject.marked`; travels in the map objects' static patch and leaves with the object, so a felled tree's Stump starts unmarked): `markKindOf(type)` (`fell` for the `hunting.forest` tree, `dig` for what a building `digs`), `isMarked`, `canMark` (as `canPaintReserve`), `markObjects(kind, from, to)` (skips trees in a Reserve), `clearMarks(from, to, kind?)` (ignores Fog), `paintKeep` (the `paintReserve` command: the Reserve, then Fell marks off its trees).
- `forage.ts`: forage patches: `isForagePatch`, `isWithered` (reads `mapObject.withered`: no `shadedBy` tree within `shadeTiles`, Chebyshev), `refreshShade(state, content, near?)` (sets `withered` on patches within reach of `near`, or all; `createInitialState`, `fellTree` and old-save loading call it; a future planting or growing tree must too), `canForage` (stocked and shaded).
- `yards.ts`: Workplace yards (the output buffer, `logistics.yardCapacity` shared by all outputs): `yardAmount`, `yardRoom`, `outputRoom` (room for a resource it makes), `fitsInYard` (a catch, basket or batch fits whole).
- `gathering.ts`: shared by gatherers: `inWorkRadius` (from the body), `gatherTargets` (objects a hut gathers, or of the `types` given, in radius, with yard room for a whole gather), `walkToNearest` (nearest by walking distance, ties by ID).
- `huntingGrounds.ts`: Hunting grounds (`state.components.huntingGround`, tile sets as ascending tile indices, no `tile`): `addHuntingGround(state, content, name, tiles, maxGame)` (maps' rectangles go through it, a generator can too; counts `startTrees`, `staticChanged`), `inGround(state, ground, tile)` (binary search), `groundTiles`, `groundMiddle` (the label/alert tile: nearest the mean, ties to the later tile, a rectangle's middle), `groundAt(tile)`, `standingTrees`, `groundCeiling` (capped at `maxGame`), `huntChancePermille`, `groundHealth` (`GroundHealth`), `groundsNear(type, origin)` (reach of a building not yet placed), `groundsInReach(id)`, `lodgeGrounds(id)` (a lodge's chosen ground, else all in reach), `setHuntingGround` (the `setHuntingGround` command; a lodge's choice is `BuildingComponent.huntingGround`), `groundTilesInReach`, `loseGame` (every Game loss: a catch, fleeing; at 0 sets `regrowsOn` to the first day after `emptySeasons` full seasons, else starts the recovery clock), `regrowGame` (at a Dawn: returns `returningGame` (≤ ceiling) to an empty ground on its day, else +1 every `recoveryDays` while under the ceiling), `groundRegrowth` (`GroundRegrowth` for the panel: `empty` with days or null (no trees), `recovering`), and `fellTree` (every tree felling goes through it: the tree becomes a Stump (`leaveStump`), surplus Game flees, counted in `fled`).
- `deaths.ts`: `killVillager(state, content, id, cause)`: records `{name, cause, day}` in `state.deaths`, drops its haul, destroys the entity (goods in hand lost; Home and Workplace position free up, staffing re-drafts); sets `state.gameOver` when it was the last villager.
- `alerts.ts`: `alerts(state, content)`: derived, never stored; `Alert` = `AlertData` (union by `kind`: red `willStarve`/`willFreeze`; amber `lowFood`, `winterFood`, `noFirewood`, `lowFirewood`, `hungry`/`cold`/`homeless`, `scarceGround`, target `groundMiddle`) + `severity` + `target` tile. `winterIn` (days left before winter through autumn, else null).
- `bottlenecks.ts`: `workplaceStatus(state, content, building)` → `WorkplaceStatus` (`noWorker` from `openPositions`; for workshops `waitingFor`/`outputFull` with the resources, via production's `recipeBlockers`; for gathering Workplaces `outputFull` via `gathererNoRoom`; `noGame` for a hunter's lodge whose grounds are empty) or null while it works or is paused. Derived, never stored.
- `traffic.ts`: the last in-game day as `TRAFFIC_SLICES` (24) slices in `state.traffic`: `currentSlice` (starts a slice, drops ones out of the window), `countStep` (movement calls it: a Carrier onto a Road tile), `carrierUtilization` (whole % of Carrier-ticks at work spent holding a Haul, null with no samples), `roadTraffic` (steps per Road tile index).
- `homes.ts`: `homesSystem` (clears Homes that are gone, gives Homeless villagers a free place), `nearestHouseWithRoom(from)`, `housePlaces`, `residentsOf`, `homeDoor`, `isAtHome`.
- `warmth.ts`: House fuel (firewood in `building.stock`): `isHouse`, `isStockingUp` (autumn–winter), `isColdSeason`, `fuelIn`, `houseFuelRoom` (the `house` demand), `isColdHouse` (for the client icon).
- `lights.ts`: Light (ADR-0003). `lightDef`, `lightFuelIn`, `lightFuelRoom` (the `light` demand, every season), `isDarkLight` (client icon: at night not `lit`, by day under a night's fuel), `litGrid` (tiles lit tonight, Chebyshev `radiusTiles` round each `lit` light's footprint), `lightReachGrid` (same for every light, fuelled or not; budding avoids it), `lightSources(state, content)` → `LightSource[]` (`{id, kind: 'window'}` for each House at night with a resident at Home that isn't `cold`, windows give no Light; `{id, kind: 'light', radiusTiles}` for each lit torch/brazier).

## The tick: `sim/src/step.ts` `step(state, commands, content)`
Clones state (JSON) and hands the map cache to the clone (`inheritMapCache`), then `stepInPlace` runs: 1 `applyCommand` per command (`commands.ts`) → 2 `movementSystem` → 3 `homesSystem` (`homes.ts`) → 4 `spoilageSystem` (Dawn only) → 5 `growthSystem` (Dawn only) → 6 `huntingGroundsSystem` (Dawn only) → 7 `patchesSystem` (season's first Dawn) → 8 `warmthSystem` (winter Dusk, Dawn) → 9 `lightsSystem` (Dusk, Dawn) → 10 `routineSystem` → 11 `immigrationSystem` (Dawn only) → 12 `densSystem` (Dawn, Dusk, rate 0) → 13 `militiaSystem` → 14 `combatSystem` → 15 `heroSystem` (`hero.ts`) → 16 `woodcuttingSystem` → 17 `fishingSystem` → 18 `foragingSystem` → 19 `huntingSystem` → 20 `forestrySystem` → 21 `productionSystem` → 22 `haulingSystem` → 23 `constructionSystem` (skips at night) → 24 `staffingSystem` → 25 `fogSystem` → 26 `trafficSystem` → `tick += 1`. Movement also counts Carrier road steps (`countStep`) and walks Gloamlings (`content.combat.gloamling.walkSpeed`). Systems mutate the clone.

## State (`sim/src/state.ts`)
- `GameState`: `version`, `tick`, `rng` (PRNG uint32), `nextId`, `mapVersion` (bumped by `mapChanged`; caches key on it), `staticVersion` (bumped by `staticChanged`; the worker sends a static patch when it moves), `map` (`width`, `height`, `terrain[]` row-major, `roads` by tile index, `entry` tile or null, `revealed` and `inSight` as `TileBits`: one bit per tile, 32 to a number; old saves load with every tile Revealed; `reserve` as `TileBits`, old saves load with none), `components`, `logistics.hauls` (by carrier ID), `deaths` (`Death[]`: `name`, `cause` (`starvation` | `freezing`), `day`), `gameOver` (`{day, cause}` of the last death, or null while the game runs), `traffic` (`TrafficSlice[]`: `slice`, `carrierTicks`, `haulTicks`, `roadSteps` by tile index; oldest first, the last day only), `monsterRate` (0–100, `DEFAULT_MONSTER_RATE` 100; old saves load as 100), `fog` (Fog on/off; hand-made maps and old saves off), `calms` (`CalmArea[]`: `{tile, until}` per cleared Den, until = clearing tick + `calmDays` days).
- Combat: `villager.hp`, `villager.readyAt` (first tick it can hit again), `villager.fighting`; `hero.hp`, `hero.readyAt`, `hero.knockedOutUntil` (tick it gets up, or null); hero tasks `attack {gloamling}`, `attackDen {den}` and `search {ruins, ticksLeft}`; `den` = `{hp, readyAt}` (save backfills full HP); `gloamling` = `{den, hp, readyAt, target}` (`target` a villager, the Hero, a House, or null). `DeathCause` includes `gloamling` and `den` (stung).
- `components`: `Record<EntityId, T>` stores: `tile`, `mapObject`, `building`, `site`, `stockpile`, `villager`, `hero`, `position`, `path`, `huntingGround`, `den` (`{hp, readyAt}`; its `tile`), `cache` (`{stock}`: a cleared Den's or Searched Ruins' goods on its `tile`, gone once empty), `poi` (`{kind, searched}`: a point of interest on its `tile`), `gloamling` (`{den, hp, readyAt, target}`, with a `position` and a `path` while walking; none by day), and task stores `woodcutter`, `crafter`, `fisher`, `forager`, `hunter`, `forester` (`idle` | `toPlot {plot}` | `planting {plot, ticksLeft}`).
- `villager`: `name`, `job`, `workplace`, `carrying`, `home` (House ID or null = Homeless), `routine` (`work` | `toGranary` | `goingHome` | `asleep` | `toTower` | `onWatch`, the last two a Watchman's), `sleptTicks` (at Home, this night), `tired`, `missedMeals` (Hungry when > 0), `coldNights` (Cold when > 0), `militia` (called by the bell; routine waits).
- `huntingGround`: `name`, `tiles` (ascending tile indices, fixed once the map stands), `maxGame`, `game`, `startTrees`, `fled`, `regrowsOn` (day whose Dawn brings Game back: the returning animals while empty, the next animal while under the ceiling; null when nothing is due).
- `mapObject.withered`: forage patches only, kept by `refreshShade`. `mapObject.growsAt` (the tick from which it grows, applied at the next Dawn) and `stage` (drawing stage from 0): Saplings only. `mapObject.marked`: `true` on a tree or Stump the player marked (`marks.ts`), else absent.
- `building.rotation` / `site.rotation`: `Rotation` 0–3, quarter turns clockwise from the content layout (`ROTATIONS`, `isRotation` in `state.ts`).
- `building.stock`: output buffer (what lies in its yard), a Granary's Food, or a House's firewood; `building.input`: workshop input buffer; `building.cold`: a House unlit tonight (winter only); `building.lit`: a light that burned at tonight's Dusk (false by day); `building.hp`: a wall's HP or a House's door HP (`fullHp`), null for buildings Gloamlings don't batter.
- IDs: `createEntity(state)` takes `state.nextId++`. A site becomes a building with the same ID.
- Time: `calendarAt(state.tick, content)` → `{day, season, dayOfSeason, year, timeOfDay, isNight}`.

## How to add…
- **Resource**: `ResourceId` in `content/src/types.ts`; entry in `resources.ts`; `PIECES` in `client/src/render/shapes.ts` (type error until you do). Goods on stockpiles unless `storage: 'granary'` (Food), which needs `spoilPercent` and goes to Granaries and Meals automatically.
- **Building**: `BuildingId` + def in `content/src/buildings.ts` (new fields go in `BuildingDef`, `types.ts`; check `content/test/validate.test.ts`). Placement is generic (`grid.ts` `canPlaceBuilding`); special rules go there. Rendering: `drawBuilding` in `render/buildingArt.ts` (give it its own look there, or it's a plain log cabin) unless special-cased in `WorldRenderer.syncStatics` (like `chopping_block`). Toolbar: `TOOLS` in `client/src/game/Game.ts`.
- **Command**: add to `Command` union + case in `applyCommand` (`sim/src/commands.ts`), logic in its module; test in `sim/test/commands.test.ts` or the feature's test; client sends it with `this.bridge.command({...})` from a `Game` method, wired to a button in `ui/Hud.tsx`.
- **System**: `sim/src/systems/<name>.ts` exporting `<name>System(state, content)`; call it in `step.ts` and update the order comment; loop with `idsOf`; use `workTicks` (aura) for work timers.
- **Villager task/activity**: task union in `state.ts`, store in `Components` and `createEmptyState` (`map.ts`); init/clear in `assignJob` (`villagers.ts`); undo work in progress in `release` (`workers.ts`); new Job: `JobId` + `jobs.ts` + `JOB_COLORS` (`WorldRenderer.ts`) + palette colour; animation in `drawVillagers`. Missing stores in old saves backfill automatically; new fields in existing components need a line in `save.ts` `normalizeLoadedState` (breaking change: bump `STATE_VERSION`).
