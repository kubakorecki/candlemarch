# Code map

Orientation for agents. Read before exploring; update when a module is added, moved or renamed.

## content (`packages/content/src`): typed data, no logic
- `types.ts`: every ID union (`ResourceId`, `BuildingId`, `JobId`, `RecipeId`, `TerrainId`, `MapObjectId`, `RoadId`, `HeroId`, `SeasonId`) and def shape (`BuildingDef`, `RecipeDef`, `JobDef`, `CalendarDef`, `NeedsDef`...), plus the `Content` aggregate.
- `index.ts`: assembles and exports `content: Content`; re-exports all types.
- `resources.ts` (`GoodsDef` on stockpiles | `FoodDef` in a Granary with `spoilPercent`; `meat` is Food, `hides` pile up on Stockpiles), `recipes.ts`, `buildings.ts` (size, door, employs, `gathers` list + `workRadius`, `hunts` (hunt ticks, catch), `outputBuffer` slots per resource, input buffers, recipes, `residents` (makes it a House), `foodCapacity` (makes it a Granary), construction cost), `jobs.ts` (walk speed, carry, idle retry), `mapObjects.ts` (tree; forage patches `berry_bush`, `mushroom_patch` with a `forage` def: stock per season, shade), `terrain.ts`, `roads.ts`, `heroes.ts` (aura), `logistics.ts` (stockpile tile capacity), `calendar.ts` (dayTicks 3600, seasons, night length, riverFrozen, spoilPercent), `needs.ts` (Tired: min sleep %, speed %; Hungry: meal units, speed %, starve after; Cold: fuel, House buffer, burn per night, stock-up and cold seasons, speed %, freeze after), `hunting.ts` (`HuntingDef`: forest map object, max catch permille, health-word thresholds), `immigration.ts` (`ImmigrationDef`: Meals a head, closed seasons), `alerts.ts` (`AlertsDef`: `lowFoodDays`), `dens.ts` (`DensDef`: Gloamlings `spawnsPerDusk` per season, `darkRingTiles`, `budding` band, distance and cap), `combat.ts` (`CombatDef`: a `FighterDef` (HP, damage, cooldown ticks, reach tiles) for `gloamling` (plus walk speed, sight) and `villager`), `villagerNames.ts`.

## sim (`packages/sim/src`): pure, deterministic
- `index.ts`: public API; the client and tooling import only from here. Export new helpers here.
- `state.ts`: `GameState`, `Components`, all component and task types, `STATE_VERSION`, `TICKS_PER_SECOND`, `TILE_UNITS` (1000), `DIAGONAL_UNITS`.
- `step.ts`: `step()`, the tick (see below); `stepInPlace()` runs the same tick without the copy, for long headless runs that own their state (the balance harness). `commands.ts`: `Command` union + `applyCommand()` switch.
- `entities.ts`: `createEntity`, `destroyEntity` (clears every store), `idsOf` (sorted IDs; use for any ordered loop).
- `rng.ts`: mulberry32 over `state.rng`: `seedRng`, `nextU32`, `randomInt(state, n)`.
- `calendar.ts`: derived from `state.tick`, nothing stored: `calendarAt`, `isNight`, `isDawn`, `isDusk`, `dawnTick`, `duskTick`, `isRiverFrozen`.
- `map.ts`: `MapDef` (optional `entry` tile on the edge where Newcomers arrive → `state.map.entry`; optional `huntingGrounds` rectangles, created last so they never shift other IDs; start goods: `buildings[].stock`, `stockpiles[].goods`, checked to fit), `MAP_LEGEND` (`.` grass, `T` tree, `b` berry bush, `m` mushroom patch, `=` path, `~` river, `D` Den), `createEmptyState`, `createInitialState(seed, map, content, monsterRate = 100)`.
- `maps/`: `camp` (default: the Starting Camp, Pinewood, Old Wood Hunting ground with forage patches, river on the south edge), `meadow` (milestone 0; tests rely on its IDs), `shortHaul`, `longHaul`, `branchingNetwork`; `index.ts` has `maps`, `MapName`, `DEFAULT_MAP`.
- `grid.ts`: tile maths (`tileIndex`, `tileAt`, `tileCenter`, `tileOfPoint`, `rectTiles`), `buildingLayout(def, origin, rotation)` → `BuildingLayout` (`origin`, turned `size`, `tiles`, `door`; the one place content `size`/`door` are read), `entityLayout`, `footprint`, `doorTile`, `entityDoor`, `blockedGrid`, `standingTiles`, `isRiverbank`, `fitsAt` (keeps the entry tile clear and every footprint tile out of a Den's dark ring), `canPlaceBuilding` (both take an optional `rotation`).
- `pathfinding.ts`: A* `findPath`, `travelCosts` (Dijkstra), `tileDistance`; road-aware costs.
- `roads.ts`: `lShapeTiles`, `canLayPath`, `layPath`, `removePath`, road speed grids.
- `stockpiles.ts`: place/remove, `isStockpileGood`, `stockpileTakes`, per-tile `amountOnTile`/`roomOnTile`/`takeFromTile`/`addToTile`.
- `villagers.ts`: `spawnVillager` (every field set, no Home), `drawVillagerName`, `assignJob` (sets job + workplace, resets task store for the job), `isAtWork(v)` (routine `work` and not `fighting`; work systems, dispatch and traffic use it).
- `workers.ts`: `maxWorkers`, `workersAt`, `vacantPositions`, `reassignTargets`, `unassignWorker`, `reassignWorker`, `setWorkerLimit`, `dropWork` (the unassign rule for work in hand, keeping the Job: goods to the Workplace, haul dropped, task back to idle, stop at next tile).
- `hero.ts`: `HeroOrder`, `heroOf`, `orderHero`, `heroOrderAt` (what a right-click means), `heroSystem`.
- `aura.ts`: hero production aura: `workSpeedPercent`, `boostedWorkplaces`.
- `speed.ts`: the shared slowdown helper. `speedPercent(state, content, villager, workplace?)` = worst slowdown (Tired, Hungry, Cold) × aura at `workplace`; `workTicks(state, content, worker, workplace, ticks)` (apply to any work timer). Movement scales walking by `speedPercent` without a workplace.
- `granary.ts`: Granaries (Food in `building.stock`): `isFood`, `foodIds`, `isGranary`, `foodIn`, `granaryRoom`, `villageFood`, `baseSpoilPercent`, `eatingOrder` (fastest-spoiling first), `hasMeal`, `takeMeal`, `nearestGranaryWithMeal`.
- `forage.ts`: forage patches: `isForagePatch`, `isWithered` (no `shadedBy` tree within `shadeTiles`, Chebyshev; derived), `canForage` (stocked and shaded).
- `gathering.ts`: shared by gatherers: `outputRoom` (room in an output slot), `inWorkRadius`, `gatherTargets` (objects a hut gathers, in radius, with buffer room), `walkToNearest` (nearest by walking distance, ties by ID).
- `huntingGrounds.ts`: Hunting grounds (`state.components.huntingGround`, rectangles, no `tile`): `inGround`, `standingTrees`, `groundCeiling`, `huntChancePermille`, `groundHealth` (`GroundHealth`), `groundsNear(type, origin)` (reach of a building not yet placed), `groundsInReach(id)`, `groundTilesInReach`, and `fellTree` (every tree felling goes through it: destroys the tree, surplus Game flees, counted in `fled`).
- `deaths.ts`: `killVillager(state, content, id, cause)`: records `{name, cause, day}` in `state.deaths`, drops its haul, destroys the entity (goods in hand lost; Home and Workplace position free up, staffing re-drafts); sets `state.gameOver` when it was the last villager.
- `alerts.ts`: `alerts(state, content)`: derived, never stored; `Alert` = `AlertData` (union by `kind`: red `willStarve`/`willFreeze`; amber `lowFood`, `winterFood`, `noFirewood`, `lowFirewood`, `hungry`/`cold`/`homeless`, `scarceGround`) + `severity` + `target` tile. `winterIn` (days left before winter through autumn, else null).
- `bottlenecks.ts`: `workplaceStatus(state, content, building)` → `WorkplaceStatus` (`noWorker` from `openPositions`; for workshops `waitingFor`/`outputFull` with the resources, via production's `recipeBlockers`) or null while it works or is paused. Derived, never stored.
- `traffic.ts`: the last in-game day as `TRAFFIC_SLICES` (24) slices in `state.traffic`: `currentSlice` (starts a slice, drops ones out of the window), `countStep` (movement calls it: a Carrier onto a Road tile), `carrierUtilization` (whole % of Carrier-ticks at work spent holding a Haul, null with no samples), `roadTraffic` (steps per Road tile index).
- `homes.ts`: `homesSystem` (clears Homes that are gone, gives Homeless villagers a free place), `nearestHouseWithRoom(from)`, `housePlaces`, `residentsOf`, `homeDoor`, `isAtHome`.
- `warmth.ts`: House fuel (firewood in `building.stock`): `isHouse`, `isStockingUp` (autumn–winter), `isColdSeason`, `fuelIn`, `houseFuelRoom` (the `house` demand), `isColdHouse` (for the client icon).
- `lights.ts`: `lightSources(state, content)` → `LightSource[]` (`{id, kind: 'window'}`), what the client glows: at night, each House with a resident at Home that isn't `cold`. Derived; windows give no Light (ADR-0003). Torches and braziers (ticket 06) join here.
- `dens.ts`: Dens (`state.components.den`, a `tile`, not a map object: not gathered, doesn't block walking) and the Monster rate: `isMonsterRate` (whole 0–100), `denTiles`, `inDarkRing` (Chebyshev `darkRingTiles` of a Den; `fitsAt` uses it), `darkRingTiles(state, content)` (every ringed tile, for the placement preview).
- `combat.ts`: derived combat helpers: `isOutInTheOpen` (a villager not asleep at Home, or the Hero), `isLivedInHouse`, `inReach` (Chebyshev tiles), `chebyshev`, `isEngaged` (a Gloamling with a villager/Hero target in reach), `attackersOf(villager)`, `opponentOf(villager)`, `targetTile`, `healthBars` (`HealthBar` for the client).
- `save.ts`: `serialize`, `deserialize` → `normalizeLoadedState` (backfills fields added since the save).
- `logistics/jobDispatch.ts`: carriers: `Haul`, `LogisticsState`, `updateHauls`, `abandonHaul`, `isCarrierIdle`, reservations. ADR 0001.
- `logistics/supplyDemand.ts`: `listSupplies`, `listDemands` (sites, workshop inputs, Granaries, House fuel, stockpiles), `inputRoom`.
- `systems/movement.ts`: `movementSystem`, `walkTo`, `rerouteTo`, `stopAtNextTile`, `isAt`, `villagerTile`, `walkGrid`.
- `systems/patches.ts`: `patchesSystem`: at each season's first Dawn but the first, sets every patch's stock to the season's amount (0 if withered).
- `systems/woodcutting.ts`, `fishing.ts`, `foraging.ts` (forager: nearest stocked, shaded patch in radius → hut buffer; patches stay when empty), `hunting.ts` (hunter: nearest ground in radius with Game → hunt → PRNG roll → bag back to the lodge; the bag lives in the task, not `carrying`), `production.ts` (workshops; `isPaused`, `recipeBlockers`, `villageStock` (House fuel counts for firewood)), `hauling.ts` (calls `updateHauls`), `construction.ts`, `staffing.ts` (`openPositions`). Work systems and dispatch skip villagers whose `routine` isn't `work`.
- `systems/dens.ts`: `densSystem`: at Monster rate 0 clears Gloamlings every tick; at Dawn Gloamlings vanish and, at each season's first Dawn but the first, each Den (ID order, up to `maxDens`) buds on an open tile within `closerMax` of it, `closerMin`–`closerMax` closer (Chebyshev) to the nearest building or site and ≥ `minBuildingTiles` from all, picked with `randomInt` among candidates in tile-index order; at Dusk each Den spawns `trunc(n × rate ÷ 100)` Gloamlings (`gloamling {den}` + `position` at the Den tile centre).
- `systems/combat.ts`: `combatSystem`: at Dawn villagers back to full HP; with Gloamlings out, each (ID order) keeps its villager/Hero target or picks the nearest in sight (Chebyshev `sightTiles`, then walking cost, ties to ID), else the nearest lived-in House; walks after it (`rerouteTo` when the target's tile changes, `stopAtNextTile` once in reach; waits at a House door); villagers with an attacker in reach start `fighting` (`dropWork`); then hits in ID order (Gloamling → its target, villager → `opponentOf`), `readyAt` cooldowns; a villager at 0 HP dies (`killVillager`, cause `gloamling`), a Gloamling is destroyed. The Hero takes no damage yet (ticket 05).
- `systems/traffic.ts`: `trafficSystem` (last in the tick): adds Carriers at work (routine `work`) and those holding a Haul to the current slice.
- `systems/spoilage.ts`: `spoilageSystem` (each Dawn but the first, Food in every building's `stock`/`input` loses `ceil(amount × rate%)`), `spoilPercentAt` (Food rate × season rate); `storeSpoilPercent` is where M6's root cellar lowers it.
- `systems/warmth.ts`: `warmthSystem`: at a winter Dusk each House with residents burns fuel or sets `building.cold`; at Dawn each villager's `coldNights` goes up after a winter night not asleep at a warm Home, else resets; the 2nd in a row freezes it (`killVillager`); flags cleared.
- `systems/immigration.ts`: `immigrationSystem` (each Dawn but the first: one Carrier Newcomer at `state.map.entry`, Home = `newcomerHome`, routine `goingHome`), `newcomerHome` (null when shut: no entry/House reachable with room/Food/closed season), `immigrationFoodNeeded`.
- `systems/routine.ts`: `routineSystem`, the Dusk/Dawn routine on `villager.routine` (`work` → `toGranary` → `goingHome` → `asleep`): `finishWork` (what's dropped or finished at Dusk), `seekMeal` (nearest Granary with a Meal, eat, or go home Hungry), `goHome`, sleep counting, Tired set at Dawn and cleared at Dusk, a Meal missed at Dawn; `missMeal` starves a villager at the 3rd missed Meal in a row; by day a `goingHome` villager (a Newcomer) whose walk ended starts `work`.

## The tick: `sim/src/step.ts` `step(state, commands, content)`
Clones state (JSON), then `stepInPlace` runs: 1 `applyCommand` per command (`commands.ts`) → 2 `movementSystem` → 3 `homesSystem` (`homes.ts`) → 4 `spoilageSystem` (Dawn only) → 5 `patchesSystem` (season's first Dawn) → 6 `warmthSystem` (winter Dusk, Dawn) → 7 `routineSystem` → 8 `immigrationSystem` (Dawn only) → 9 `densSystem` (Dawn, Dusk, rate 0) → 10 `combatSystem` → 11 `heroSystem` (`hero.ts`) → 12 `woodcuttingSystem` → 13 `fishingSystem` → 14 `foragingSystem` → 15 `huntingSystem` → 16 `productionSystem` → 17 `haulingSystem` → 18 `constructionSystem` (skips at night) → 19 `staffingSystem` → 20 `trafficSystem` → `tick += 1`. Movement also counts Carrier road steps (`countStep`) and walks Gloamlings (`content.combat.gloamling.walkSpeed`). Systems mutate the clone.

## State (`sim/src/state.ts`)
- `GameState`: `version`, `tick`, `rng` (PRNG uint32), `nextId`, `map` (`width`, `height`, `terrain[]` row-major, `roads` by tile index, `entry` tile or null), `components`, `logistics.hauls` (by carrier ID), `deaths` (`Death[]`: `name`, `cause` (`starvation` | `freezing`), `day`), `gameOver` (`{day, cause}` of the last death, or null while the game runs), `traffic` (`TrafficSlice[]`: `slice`, `carrierTicks`, `haulTicks`, `roadSteps` by tile index; oldest first, the last day only), `monsterRate` (0–100, `DEFAULT_MONSTER_RATE` 100; old saves load as 100).
- Combat: `villager.hp`, `villager.readyAt` (first tick it can hit again), `villager.fighting`; `gloamling` = `{den, hp, readyAt, target}` (`target` a villager, the Hero, a House, or null). `DeathCause` includes `gloamling`.
- `components`: `Record<EntityId, T>` stores: `tile`, `mapObject`, `building`, `site`, `stockpile`, `villager`, `hero`, `position`, `path`, `huntingGround`, `den` (empty component; its `tile`), `gloamling` (`{den, hp, readyAt, target}`, with a `position` and a `path` while walking; none by day), and task stores `woodcutter`, `crafter`, `fisher`, `forager`, `hunter`.
- `villager`: `name`, `job`, `workplace`, `carrying`, `home` (House ID or null = Homeless), `routine` (`work` | `toGranary` | `goingHome` | `asleep`), `sleptTicks` (at Home, this night), `tired`, `missedMeals` (Hungry when > 0), `coldNights` (Cold when > 0).
- `building.rotation` / `site.rotation`: `Rotation` 0–3, quarter turns clockwise from the content layout (`ROTATIONS`, `isRotation` in `state.ts`).
- `building.stock`: output buffer, a Granary's Food, or a House's firewood; `building.input`: workshop input buffer; `building.cold`: a House unlit tonight (winter only).
- IDs: `createEntity(state)` takes `state.nextId++`. A site becomes a building with the same ID.
- Time: `calendarAt(state.tick, content)` → `{day, season, dayOfSeason, year, timeOfDay, isNight}`.

## How to add…
- **Resource**: `ResourceId` in `content/src/types.ts`; entry in `resources.ts`; `PIECES` in `client/src/render/shapes.ts` (type error until you do). Goods on stockpiles unless `storage: 'granary'` (Food), which needs `spoilPercent` and goes to Granaries and Meals automatically.
- **Building**: `BuildingId` + def in `content/src/buildings.ts` (new fields go in `BuildingDef`, `types.ts`; check `content/test/validate.test.ts`). Placement is generic (`grid.ts` `canPlaceBuilding`); special rules go there. Rendering: generic `drawBuilding` unless special-cased in `WorldRenderer.syncStatics` (like `chopping_block`). Toolbar: `TOOLS` in `client/src/game/Game.ts`.
- **Command**: add to `Command` union + case in `applyCommand` (`sim/src/commands.ts`), logic in its module; test in `sim/test/commands.test.ts` or the feature's test; client sends it with `this.bridge.command({...})` from a `Game` method, wired to a button in `ui/Hud.tsx`.
- **System**: `sim/src/systems/<name>.ts` exporting `<name>System(state, content)`; call it in `step.ts` and update the order comment; loop with `idsOf`; use `workTicks` (aura) for work timers.
- **Villager task/activity**: task union in `state.ts`, store in `Components` and `createEmptyState` (`map.ts`); init/clear in `assignJob` (`villagers.ts`); undo work in progress in `release` (`workers.ts`); new Job: `JobId` + `jobs.ts` + `JOB_COLORS` (`WorldRenderer.ts`) + palette colour; animation in `drawVillagers`. Missing stores in old saves backfill automatically; new fields in existing components need a line in `save.ts` `normalizeLoadedState` (breaking change: bump `STATE_VERSION`).

## Tests
- `pnpm vitest run packages/sim/test/hauling.test.ts` runs one file. `pnpm test` runs all projects (`vitest.config.ts`) except `*.scenario.test.ts`; `pnpm test:scenarios` runs those. A test that plays months of game time is a scenario test.
- `sim/test/helpers.ts`: `run(state, ticks, commandsAt)`, `runUntil(state, done, max, commandsAt)`, `totalLogs`, `woodcuttersHutStock`, re-exported `content`.
- Small maps: inline `MapDef` constants in each test file (e.g. `yard` in `construction.test.ts`, `riverMap()` in `river.test.ts`), built with `createInitialState(seed, map, content)`.
- Determinism: `sim/test/milestone.test.ts` ("is deterministic"). Save/load continuation: `sim/test/scenarios.test.ts` (branching network), `hero.test.ts` (mid-walk) and `sleep.test.ts` (mid-night); format/backfill in `save.test.ts`.
- Spoilage: `sim/test/spoilage.test.ts` (`dawnWith(day, stock)` runs one Dawn with 1 tick; a test `Content` makes logs a Food at 50%).
- Forage patches and the forager: `sim/test/foraging.test.ts` (`dawnOf(s, day)` jumps to a Dawn and runs it).
- Hunting grounds and the hunter: `sim/test/hunting.test.ts` (`camp` map: 8 trees in a 6×4 ground, a lodge; the catch-chance test rigs `state.rng` so the next roll is known).
- Warmth and Cold: `sim/test/warmth.test.ts` (`camp`: a Hut, a stockpile, a Carrier; `night(s, day)` jumps to a Dusk and runs past the next Dawn; `speedWhenFed` ignores Hungry/Tired).
- Immigration: `sim/test/immigration.test.ts` (`camp`: Hut, Granary, one Carrier, entry (0,3); `campAt(day, fish)` jumps to a Dawn; `noSpoiling` content).
- Alerts: `sim/test/alerts.test.ts` (`village`: Hut, Granary, 4 Carriers (one Homeless), Old Wood; `villageAt(tick, {food, firewood})` jumps and fills; `alertOf(s, kind)`). Game over: end of `death.test.ts`.
