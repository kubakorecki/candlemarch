# Code map

Orientation for agents. Read before exploring; update when a module is added, moved or renamed.

## content (`packages/content/src`): typed data, no logic
- `types.ts`: every ID union (`ResourceId`, `BuildingId`, `JobId`, `RecipeId`, `TerrainId`, `MapObjectId`, `RoadId`, `HeroId`, `SeasonId`) and def shape (`BuildingDef`, `RecipeDef`, `JobDef`, `CalendarDef`, `NeedsDef`...), plus the `Content` aggregate.
- `index.ts`: assembles and exports `content: Content`; re-exports all types.
- `resources.ts` (`GoodsDef` on stockpiles | `FoodDef` in a Granary with `spoilPercent`; `meat` is Food, `hides` pile up on Stockpiles), `recipes.ts`, `buildings.ts` (size, door, employs, `gathers` list + `workRadius`, `hunts` (hunt ticks, catch), `outputBuffer` slots per resource, input buffers, recipes, `residents` (makes it a House), `foodCapacity` (makes it a Granary), `light` (`LightDef`: radius, fuel, burn a night, holds; makes it a light: `torch`, `brazier`), `bell` (`BellDef`: `rangeTiles`; makes it the Militia bell), `watch` (`WatchDef`: `rangeTiles`, `damage`, `cooldownTicks`; makes it a watchtower, which employs a `watchman`), `wall` (`WallDef`: `hp`, `gate`; makes it a 1×1 wall segment, `palisade` or `gate`, whose door is its own tile), `onePerVillage`, construction cost), `jobs.ts` (walk speed, carry, idle retry; `watchman` works nights), `mapObjects.ts` (tree; forage patches `berry_bush`, `mushroom_patch` with a `forage` def: stock per season, shade), `terrain.ts`, `roads.ts`, `heroes.ts` (aura), `logistics.ts` (stockpile tile capacity), `calendar.ts` (dayTicks 3600, seasons, night length, riverFrozen, spoilPercent), `needs.ts` (Tired: min sleep %, speed %; Hungry: meal units, speed %, starve after; Cold: fuel, House buffer, burn per night, stock-up and cold seasons, speed %, freeze after), `hunting.ts` (`HuntingDef`: forest map object, max catch permille, health-word thresholds), `immigration.ts` (`ImmigrationDef`: Meals a head, closed seasons), `alerts.ts` (`AlertsDef`: `lowFoodDays`), `dens.ts` (`DensDef`: Gloamlings `spawnsPerDusk` per season, `darkRingTiles`, `budding` band, distance and cap, `cleared` (cache goods, `calmTiles`, `calmDays`)), `combat.ts` (`CombatDef`: a `FighterDef` (HP, damage, cooldown ticks, reach tiles) for `gloamling` (plus walk speed, sight), `villager` and `hero` (plus `knockoutTicks`) and `den` (its HP and sting); `houseDoorHp`), `villagerNames.ts`.

## sim (`packages/sim/src`): pure, deterministic
- `index.ts`: public API; the client and tooling import only from here. Export new helpers here.
- `state.ts`: `GameState`, `Components`, all component and task types, `STATE_VERSION`, `TICKS_PER_SECOND`, `TILE_UNITS` (1000), `DIAGONAL_UNITS`.
- `step.ts`: `step()`, the tick (see below); `stepInPlace()` runs the same tick without the copy, for long headless runs that own their state (the balance harness). `commands.ts`: `Command` union + `applyCommand()` switch.
- `entities.ts`: `createEntity`, `destroyEntity` (clears every store), `idsOf` (sorted IDs; use for any ordered loop).
- `rng.ts`: mulberry32 over `state.rng`: `seedRng`, `nextU32`, `randomInt(state, n)`.
- `calendar.ts`: derived from `state.tick`, nothing stored: `calendarAt`, `isNight`, `isDawn`, `isDusk`, `dawnTick`, `duskTick`, `isRiverFrozen`.
- `map.ts`: `MapDef` (optional `entry` tile on the edge where Newcomers arrive → `state.map.entry`; optional `huntingGrounds` rectangles, created last so they never shift other IDs; start goods: `buildings[].stock`, `stockpiles[].goods`, checked to fit), `MAP_LEGEND` (`.` grass, `T` tree, `b` berry bush, `m` mushroom patch, `=` path, `~` river, `D` Den), `createEmptyState`, `createInitialState(seed, map, content, monsterRate = 100)`.
- `maps/`: `camp` (default: the Starting Camp, Pinewood, Old Wood Hunting ground with forage patches, river on the south edge), `meadow` (milestone 0; tests rely on its IDs), `shortHaul`, `longHaul`, `branchingNetwork`, `nights` (a standing village west of a wood with one gap, a Den past it; no Hero); `index.ts` has `maps`, `MapName`, `DEFAULT_MAP`.
- `grid.ts`: tile maths (`tileIndex`, `tileAt`, `tileCenter`, `tileOfPoint`, `rectTiles`), `buildingLayout(def, origin, rotation)` → `BuildingLayout` (`origin`, turned `size`, `tiles`, `door`; the one place content `size`/`door` are read), `entityLayout`, `footprint`, `doorTile`, `entityDoor`, `blockedGrid(state, content, gatesBlock = false)` (a wall's site and a battered-down wall block nobody, a built Gate only with `gatesBlock`), `palisadeTiles` (palisades built or not; no Road over them), `standingTiles`, `isRiverbank`, `tilesUnderCaches`, `fitsAt` (keeps the entry tile clear, off caches, and every footprint tile out of a Den's dark ring; a Gate may stand on a Road), `canPlaceBuilding` (refuses a second `onePerVillage` building, built or site; both take an optional `rotation`).
- `walls.ts`: Palisades and Gates: `fullHp(content, type)` (a wall's HP, a House's door (`combat.houseDoorHp`), else null; map start, construction, save backfill and Dawn use it), `isBrokenWall` (0 HP: blocks nobody until Dawn), `isWallType`, `isWall`, `canLayWall`/`layWall` (a site per tile of the Road's L, skipping tiles that already hold a wall; all or nothing through `canPlaceBuilding`).
- `pathfinding.ts`: A* `findPath`, `travelCosts` (Dijkstra), `tileDistance`; road-aware costs.
- `roads.ts`: `lShapeTiles`, `canLayPath` (not over a palisade or its site), `layPath`, `removePath`, road speed grids.
- `stockpiles.ts`: place/remove, `isStockpileGood`, `stockpileTakes`, per-tile `amountOnTile`/`roomOnTile`/`takeFromTile`/`addToTile`.
- `villagers.ts`: `spawnVillager` (every field set, no Home), `drawVillagerName`, `assignJob` (sets job + workplace, resets task store for the job), `isAtWork(v)` (routine `work`, not `fighting`, not `militia`; work systems, dispatch and traffic use it).
- `workers.ts`: `maxWorkers`, `workersAt`, `vacantPositions`, `reassignTargets`, `unassignWorker`, `reassignWorker`, `setWorkerLimit`, `dropWork` (the unassign rule for work in hand, keeping the Job: goods to the Workplace, haul dropped, task back to idle, stop at next tile).
- `hero.ts`: `HeroOrder` (`move`, `gather`, `deliver`, `pickup` (a building, stockpile or cache), `attack`, `attackDen`), `heroOf`, `orderHero` (refused while Knocked out), `heroOrderAt` (what a right-click means; a Gloamling on the tile → `attack`, else a Den → `attackDen`, a cache → `pickup`), `heroSystem` (an `attack` order follows its Gloamling and stands once in reach; `attackDen` walks to the Den's tile and stands once in reach; both end when the target is gone).
- `aura.ts`: hero production aura: `workSpeedPercent`, `boostedWorkplaces` (none while the hero is Knocked out).
- `speed.ts`: the shared slowdown helper. `speedPercent(state, content, villager, workplace?)` = worst slowdown (Tired, Hungry, Cold) × aura at `workplace`; `workTicks(state, content, worker, workplace, ticks)` (apply to any work timer). Movement scales walking by `speedPercent` without a workplace.
- `granary.ts`: Granaries (Food in `building.stock`): `isFood`, `foodIds`, `isGranary`, `foodIn`, `granaryRoom`, `villageFood`, `baseSpoilPercent`, `eatingOrder` (fastest-spoiling first), `hasMeal`, `takeMeal`, `nearestGranaryWithMeal`.
- `forage.ts`: forage patches: `isForagePatch`, `isWithered` (no `shadedBy` tree within `shadeTiles`, Chebyshev; derived), `canForage` (stocked and shaded).
- `gathering.ts`: shared by gatherers: `outputRoom` (room in an output slot), `inWorkRadius`, `gatherTargets` (objects a hut gathers, in radius, with buffer room), `walkToNearest` (nearest by walking distance, ties by ID).
- `huntingGrounds.ts`: Hunting grounds (`state.components.huntingGround`, rectangles, no `tile`): `inGround`, `standingTrees`, `groundCeiling`, `huntChancePermille`, `groundHealth` (`GroundHealth`), `groundsNear(type, origin)` (reach of a building not yet placed), `groundsInReach(id)`, `groundTilesInReach`, and `fellTree` (every tree felling goes through it: destroys the tree, surplus Game flees, counted in `fled`).
- `deaths.ts`: `killVillager(state, content, id, cause)`: records `{name, cause, day}` in `state.deaths`, drops its haul, destroys the entity (goods in hand lost; Home and Workplace position free up, staffing re-drafts); sets `state.gameOver` when it was the last villager.
- `alerts.ts`: `alerts(state, content)`: derived, never stored; `Alert` = `AlertData` (union by `kind`: red `willStarve`/`willFreeze`; amber `lowFood`, `winterFood`, `noFirewood`, `lowFirewood`, `hungry`/`cold`/`homeless`, `scarceGround`) + `severity` + `target` tile. `winterIn` (days left before winter through autumn, else null).
- `bottlenecks.ts`: `workplaceStatus(state, content, building)` → `WorkplaceStatus` (`noWorker` from `openPositions`; for workshops `waitingFor`/`outputFull` with the resources, via production's `recipeBlockers`) or null while it works or is paused. Derived, never stored.
- `traffic.ts`: the last in-game day as `TRAFFIC_SLICES` (24) slices in `state.traffic`: `currentSlice` (starts a slice, drops ones out of the window), `countStep` (movement calls it: a Carrier onto a Road tile), `carrierUtilization` (whole % of Carrier-ticks at work spent holding a Haul, null with no samples), `roadTraffic` (steps per Road tile index).
- `homes.ts`: `homesSystem` (clears Homes that are gone, gives Homeless villagers a free place), `nearestHouseWithRoom(from)`, `housePlaces`, `residentsOf`, `homeDoor`, `isAtHome`.
- `warmth.ts`: House fuel (firewood in `building.stock`): `isHouse`, `isStockingUp` (autumn–winter), `isColdSeason`, `fuelIn`, `houseFuelRoom` (the `house` demand), `isColdHouse` (for the client icon).
- `lights.ts`: Light (ADR-0003). `lightDef`, `lightFuelIn`, `lightFuelRoom` (the `light` demand, every season), `isDarkLight` (client icon: at night not `lit`, by day under a night's fuel), `litGrid` (tiles lit tonight, Chebyshev `radiusTiles` round each `lit` light's footprint), `lightReachGrid` (same for every light, fuelled or not; budding avoids it), `lightSources(state, content)` → `LightSource[]` (`{id, kind: 'window'}` for each House at night with a resident at Home that isn't `cold`, windows give no Light; `{id, kind: 'light', radiusTiles}` for each lit torch/brazier).
- `dens.ts`: Dens (`state.components.den` `{hp, readyAt}`, a `tile`, not a map object: not gathered, doesn't block walking) and the Monster rate: `isMonsterRate` (whole 0–100), `newDen` (full HP), `denTiles`, `denAt(tile)`, `inDarkRing` (Chebyshev `darkRingTiles` of a Den; `fitsAt` uses it), `darkRingTiles(state, content)` (every ringed tile, for the placement preview), `clearDen` (at 0 HP: destroys the Den, leaves a `cache` entity on its tile with `dens.cleared.cache`, pushes a `state.calms` record), `cacheAt(tile)`, `takeFromCache` (destroys the cache once empty; Carriers and the Hero take through it), `inCalmArea` (Chebyshev `calmTiles` of a calm record not yet ended).
- `militia.ts`: the Militia bell: `bellOf` (the bell building or null), `isBellRung` (any villager `militia`; nothing else stored), `ringBell` (the `ringBell` command: calls every villager but Watchmen with `dropWork`, or stands them down), `standDown` (flag off, stop at next tile, one called out of bed goes `goingHome`; the routine carries on), `gloamlingsNearBell` (Chebyshev `rangeTiles` of the bell's tile).
- `watchtowers.ts`: watchtowers and the Watchman (nothing stored): `isWatchman(v)`, `towerOf(id)` (its watchtower or null), `towerDoor`, `isOnWatch` (routine `onWatch` at its tower's door), `watchOf` (the tower's `WatchDef`), `towerFoe` (while on watch, the nearest Gloamling within `rangeTiles` of the tower's tile, Chebyshev, ties to ID).
- `combat.ts`: derived combat helpers: `isOutInTheOpen` (a villager in the militia or not asleep at Home and not on watch, or the Hero unless Knocked out), `isKnockedOut`, `heroFoe` (what the Hero hits: its ordered Gloamling in reach, else the nearest Gloamling in reach, else its `attackDen` Den in reach), `denInReach`, `stungBy(den)` (villagers out in the open and the Hero not Knocked out in the Den's reach, ID order), `isLivedInHouse`, `inReach` (Chebyshev tiles), `chebyshev`, `isEngaged` (a Gloamling with a villager/Hero target in reach), `batteredBy` (the House or standing wall a Gloamling targets with it in reach of its door/tile), `attackersOf(villager)`, `opponentOf(villager)`, `militiaTarget` (nearest Gloamling near the bell, tile distance), `villagerFoe` (who a villager hits: its attacker, else in the militia the nearest near the bell in reach), `targetTile`, `healthBars` (`HealthBar` for the client: fighting villagers and militia with a foe, the Hero with a Gloamling in reach, engaged Gloamlings and those a manned tower shoots (`towerFoe`), battered doors and walls with a `tile`, and a Den the Hero hits with its `tile`).
- `save.ts`: `serialize`, `deserialize` → `normalizeLoadedState` (backfills fields added since the save).
- `logistics/jobDispatch.ts`: carriers: `Haul`, `LogisticsState`, `updateHauls`, `abandonHaul`, `isCarrierIdle`, reservations. ADR 0001.
- `logistics/supplyDemand.ts`: `listSupplies` (building outputs, stockpiles, then caches: kind `cache`, picked up on the cache's tile via `haul.fromTile`, served to any demand), `listDemands` (sites, workshop inputs, Granaries, House fuel, light fuel, stockpiles, served in that order), `inputRoom`.
- `systems/movement.ts`: `movementSystem`, `walkTo`, `rerouteTo`, `stopAtNextTile`, `isAt`, `villagerTile`, `walkGrid(state, content, walker?)` (a Gloamling walker gets `gloamlingGrid`: Gates and lit tiles blocked; `walkTo`/`rerouteTo` pass the walker), `gloamlingGrid(state, content, throughWalls)` (every wall open, to find the one in the way).
- `systems/patches.ts`: `patchesSystem`: at each season's first Dawn but the first, sets every patch's stock to the season's amount (0 if withered).
- `systems/woodcutting.ts`, `fishing.ts`, `foraging.ts` (forager: nearest stocked, shaded patch in radius → hut buffer; patches stay when empty), `hunting.ts` (hunter: nearest ground in radius with Game → hunt → PRNG roll → bag back to the lodge; the bag lives in the task, not `carrying`), `production.ts` (workshops; `isPaused`, `recipeBlockers`, `villageStock` (House and light fuel count for firewood)), `hauling.ts` (calls `updateHauls`), `construction.ts`, `staffing.ts` (`openPositions`). Work systems and dispatch skip villagers whose `routine` isn't `work`.
- `systems/dens.ts`: `densSystem`: at Monster rate 0 clears Gloamlings every tick; at Dawn Gloamlings vanish, ended `state.calms` records are dropped, and, at each season's first Dawn but the first, each Den (ID order, up to `maxDens`) buds on an open tile within `closerMax` of it, `closerMin`–`closerMax` closer (Chebyshev) to the nearest building or site, ≥ `minBuildingTiles` from all, out of every light's reach (`lightReachGrid`), off caches and out of every calm area (`inCalmArea`), picked with `randomInt` among candidates in tile-index order; at Dusk each Den spawns `trunc(n × rate ÷ 100)` Gloamlings (`gloamling {den}` + `position` at the Den tile centre).
- `systems/combat.ts`: `combatSystem`: with no Gloamlings out it only resolves hits (the Hero on its Den, Den stings) when a Den stands; at Dawn villagers and the Hero back to full HP; a Knocked-out Hero gets up at full HP at `knockedOutUntil` (both run even with no Gloamlings out); with Gloamlings out, each (ID order) drops a target on a lit tile (a House: its door), keeps its villager/Hero target or picks the nearest in sight and out of Light (Chebyshev `sightTiles`, then walking cost, ties to ID), else keeps its House/wall, else one in sight behind walls, else the nearest lived-in House with a door above 0 HP (walkable first, then behind walls); walks after it (`rerouteTo` when the target's tile changes, `stopAtNextTile` once in reach; waits at a House door; stands next to a wall); when its walk fails it targets the first standing wall on the path through walls (`wallInTheWay`); villagers with an attacker in reach start `fighting` (`dropWork`); then hits in ID order (Gloamling → its target, a Watchman on watch → the tower's `towerFoe` with the tower's damage and cooldown on its own `readyAt`, villager fighting or in the militia → `villagerFoe`, Hero → `heroFoe`, a Den → every one `stungBy` it (one cooldown, `readyAt` on the Den; a villager dies of cause `den`; a Den at 0 HP → `clearDen`, it never heals); a Gloamling battering hits the door/wall's `hp`: a broken door kills the lowest-ID resident asleep at Home, a broken wall stops blocking, the Gloamling re-picks), `readyAt` cooldowns; doors and walls back to full HP at Dawn; a villager at 0 HP dies (`killVillager`, cause `gloamling`), the Hero at 0 is Knocked out (order dropped, stops at the next tile), a Gloamling is destroyed.
- `systems/militia.ts`: `militiaSystem`: while the bell rings, stands the militia down at Dawn or when the bell is gone; else each militia villager not `fighting` walks after `militiaTarget` (stands once in reach) or to the bell's door.
- `systems/traffic.ts`: `trafficSystem` (last in the tick): adds Carriers at work (routine `work`) and those holding a Haul to the current slice.
- `systems/spoilage.ts`: `spoilageSystem` (each Dawn but the first, Food in every building's `stock`/`input` loses `ceil(amount × rate%)`), `spoilPercentAt` (Food rate × season rate); `storeSpoilPercent` is where M6's root cellar lowers it.
- `systems/lights.ts`: `lightsSystem`: at every Dusk (all seasons) each light burns `burnPerNight` and sets `building.lit`, or stays dark all night; at Dawn every light's `lit` goes false.
- `systems/warmth.ts`: `warmthSystem`: at a winter Dusk each House with residents burns fuel or sets `building.cold`; at Dawn each villager's `coldNights` goes up after a winter night not asleep at a warm Home nor on watch in its tower, else resets; the 2nd in a row freezes it (`killVillager`); flags cleared.
- `systems/immigration.ts`: `immigrationSystem` (each Dawn but the first: one Carrier Newcomer at `state.map.entry`, Home = `newcomerHome`, routine `goingHome`), `newcomerHome` (null when shut: no entry/House reachable with room/Food/closed season), `immigrationFoodNeeded`.
- `systems/routine.ts`: `routineSystem`, the Dusk/Dawn routine on `villager.routine` (`work` → `toGranary` → `goingHome` → `asleep`): `finishWork` (what's dropped or finished at Dusk), `seekMeal` (nearest Granary with a Meal, eat, or go home Hungry), `goHome`, sleep counting, Tired set at Dawn and cleared at Dusk, a Meal missed at Dawn; `missMeal` starves a villager at the 3rd missed Meal in a row; by day a `goingHome` villager (a Newcomer) whose walk ended starts `work`. A Watchman: after the Meal `toTower` → `onWatch` until Dawn; by day `goingHome` → `asleep` at Home (`sleepByDay` counts `sleptTicks`); Tired set at Dusk from day sleep over the day's ticks, cleared at Dawn.

## client (`packages/client/src`)
- `main.tsx`: React root, `applyPaletteToCss`, the bundled fonts (Cinzel, EB Garamond). `ui/App.tsx`: creates `Game`, mounts `Hud` and (dev only) `NewGamePanel`.
- `protocol.ts`: `ToWorker` (`newGame {seed, map, monsterRate}`, `load`, `advance {ticks, commands}`, `save` (manual)) / `FromWorker` (`snapshot {state, prevPositions}`, `saved {slot, tick, json}`, `error`).
- `worker/sim.worker.ts`: holds `GameState`, runs `step()` N times per `advance` (commands on the first), posts an autosave (`saved`, slot `autosave`) whenever a step reaches `isAutosaveTick`, then the full state as a snapshot.
- `game/autosave.ts`: pure, shared by worker and main thread: `SaveSlot`, `SAVE_SLOTS` (localStorage keys `candlemarch.save` / `candlemarch.autosave`), `isAutosaveTick` (a Dawn but tick 0), `seasonName`, `dateLabel`, `slotDateLabel`.
- `game/SimBridge.ts`: main-thread side: owns the clock, queues commands (`command()`), sends `advance` once per frame (max 10 ticks, one request in flight; none once `state.gameOver`), exposes `state`, `prevPositions`, `alpha`.
- `game/alertText.ts`: pure wording of sim results: `alertText(alert)`, `deathText` ("Ada starved, day 14", "Wynn was killed by a Gloamling, day 3", "… was stung to death by a Den"), `gameOverText`, `knockoutText` ("Knocked out, up in 14 s"), `winterText`, `workplaceStatusText` ("Waiting for logs"), `utilizationText` ("64%").
- `game/clock.ts`: `tickClock`, `tickFraction`, `SPEEDS` (0–3).
- `game/tools.ts`: `ToolId`, `TOOLS` (build and demolish tools in order, shortcut key, `drag`, hint), `toolDef`.
- `game/almanac.ts`: pure `dayTrack(tick)` → `{phase (dawn/day/dusk/night, following `render/night.ts`), progress (in `DAY_TRACK_STEPS`), duskAt}` for the Almanac. `game/ledger.ts`: pure `stockpileGoods(state)` (goods on Stockpiles by resource).
- `game/Game.ts`: glue: input → `bridge.command(...)`, `HudState` store (`subscribe`/`getHud`; date parts, `dayTrack`, `villagers`, `goods`, `carriersBusyPercent`), selection panels (`VillagerInfo` (with `jobId`), `BuildingInfo` (`type`, `holds` from its output buffers; a lodge lists its `grounds`), `PatchInfo` (its `resource`) with the "no shade" hint, `GroundInfo`, `WorkersView`; `BuildingInfo.status` words `workplaceStatus`), readout `carriersBusy` and `heroKnockout`, right-click on a Gloamling (`hitGloamling`) orders an attack (a Den or cache on the tile goes through `heroOrderAt`), `updateCursor` (crosshair over a Gloamling or a Den (`denAt`) while the hero is selected and up), `toggleHeatMap` (Traffic button, key `t`), `setMonsterRate` (dev) and HUD `monsterRate`, a building ghost's `darkRing` (from `darkRingTiles`), `rotation` of the next building (`E` clockwise, `Q` anticlockwise), `placementWarning` (a building that fells the forest reaching a Hunting ground), `refreshAlerts` (HUD `alerts`, `deathLog`, `winter`; `gameOver`), `focusAlert(tile)` (camera jump), save/load via localStorage (`onSaved` writes the slot's key; `toggleLoadMenu` lists both slots with their date; `load(slot)`); `newGame(map, monsterRate)`. Build keys: torch `l`, brazier `z`, Militia bell `k`, watchtower `y`, drag tools palisade `p` and Gate `n` (`layWall`, `canLayWall` ghost with the dark ring). HUD `bell` (`{ringing}` or null without one), `ringBell()` (the Almanac's bell button and the bell's panel, `BuildingInfo.bell`).

## The tick: `sim/src/step.ts` `step(state, commands, content)`
Clones state (JSON), then `stepInPlace` runs: 1 `applyCommand` per command (`commands.ts`) → 2 `movementSystem` → 3 `homesSystem` (`homes.ts`) → 4 `spoilageSystem` (Dawn only) → 5 `patchesSystem` (season's first Dawn) → 6 `warmthSystem` (winter Dusk, Dawn) → 7 `lightsSystem` (Dusk, Dawn) → 8 `routineSystem` → 9 `immigrationSystem` (Dawn only) → 10 `densSystem` (Dawn, Dusk, rate 0) → 11 `militiaSystem` → 12 `combatSystem` → 13 `heroSystem` (`hero.ts`) → 14 `woodcuttingSystem` → 15 `fishingSystem` → 16 `foragingSystem` → 17 `huntingSystem` → 18 `productionSystem` → 19 `haulingSystem` → 20 `constructionSystem` (skips at night) → 21 `staffingSystem` → 22 `trafficSystem` → `tick += 1`. Movement also counts Carrier road steps (`countStep`) and walks Gloamlings (`content.combat.gloamling.walkSpeed`). Systems mutate the clone.

## State (`sim/src/state.ts`)
- `GameState`: `version`, `tick`, `rng` (PRNG uint32), `nextId`, `map` (`width`, `height`, `terrain[]` row-major, `roads` by tile index, `entry` tile or null), `components`, `logistics.hauls` (by carrier ID), `deaths` (`Death[]`: `name`, `cause` (`starvation` | `freezing`), `day`), `gameOver` (`{day, cause}` of the last death, or null while the game runs), `traffic` (`TrafficSlice[]`: `slice`, `carrierTicks`, `haulTicks`, `roadSteps` by tile index; oldest first, the last day only), `monsterRate` (0–100, `DEFAULT_MONSTER_RATE` 100; old saves load as 100), `calms` (`CalmArea[]`: `{tile, until}` per cleared Den, until = clearing tick + `calmDays` days).
- Combat: `villager.hp`, `villager.readyAt` (first tick it can hit again), `villager.fighting`; `hero.hp`, `hero.readyAt`, `hero.knockedOutUntil` (tick it gets up, or null); hero tasks `attack {gloamling}` and `attackDen {den}`; `den` = `{hp, readyAt}` (save backfills full HP); `gloamling` = `{den, hp, readyAt, target}` (`target` a villager, the Hero, a House, or null). `DeathCause` includes `gloamling` and `den` (stung).
- `components`: `Record<EntityId, T>` stores: `tile`, `mapObject`, `building`, `site`, `stockpile`, `villager`, `hero`, `position`, `path`, `huntingGround`, `den` (`{hp, readyAt}`; its `tile`), `cache` (`{stock}`: a cleared Den's goods on its `tile`, gone once empty), `gloamling` (`{den, hp, readyAt, target}`, with a `position` and a `path` while walking; none by day), and task stores `woodcutter`, `crafter`, `fisher`, `forager`, `hunter`.
- `villager`: `name`, `job`, `workplace`, `carrying`, `home` (House ID or null = Homeless), `routine` (`work` | `toGranary` | `goingHome` | `asleep` | `toTower` | `onWatch`, the last two a Watchman's), `sleptTicks` (at Home, this night), `tired`, `missedMeals` (Hungry when > 0), `coldNights` (Cold when > 0), `militia` (called by the bell; routine waits).
- `building.rotation` / `site.rotation`: `Rotation` 0–3, quarter turns clockwise from the content layout (`ROTATIONS`, `isRotation` in `state.ts`).
- `building.stock`: output buffer, a Granary's Food, or a House's firewood; `building.input`: workshop input buffer; `building.cold`: a House unlit tonight (winter only); `building.lit`: a light that burned at tonight's Dusk (false by day); `building.hp`: a wall's HP or a House's door HP (`fullHp`), null for buildings Gloamlings don't batter.
- IDs: `createEntity(state)` takes `state.nextId++`. A site becomes a building with the same ID.
- Time: `calendarAt(state.tick, content)` → `{day, season, dayOfSeason, year, timeOfDay, isNight}`.

## How to add…
- **Resource**: `ResourceId` in `content/src/types.ts`; entry in `resources.ts`; `PIECES` in `client/src/render/shapes.ts` (type error until you do). Goods on stockpiles unless `storage: 'granary'` (Food), which needs `spoilPercent` and goes to Granaries and Meals automatically.
- **Building**: `BuildingId` + def in `content/src/buildings.ts` (new fields go in `BuildingDef`, `types.ts`; check `content/test/validate.test.ts`). Placement is generic (`grid.ts` `canPlaceBuilding`); special rules go there. Rendering: generic `drawBuilding` unless special-cased in `WorldRenderer.syncStatics` (like `chopping_block`). Toolbar: `TOOLS` in `client/src/game/Game.ts`.
- **Command**: add to `Command` union + case in `applyCommand` (`sim/src/commands.ts`), logic in its module; test in `sim/test/commands.test.ts` or the feature's test; client sends it with `this.bridge.command({...})` from a `Game` method, wired to a button in `ui/Hud.tsx`.
- **System**: `sim/src/systems/<name>.ts` exporting `<name>System(state, content)`; call it in `step.ts` and update the order comment; loop with `idsOf`; use `workTicks` (aura) for work timers.
- **Villager task/activity**: task union in `state.ts`, store in `Components` and `createEmptyState` (`map.ts`); init/clear in `assignJob` (`villagers.ts`); undo work in progress in `release` (`workers.ts`); new Job: `JobId` + `jobs.ts` + `JOB_COLORS` (`WorldRenderer.ts`) + palette colour; animation in `drawVillagers`. Missing stores in old saves backfill automatically; new fields in existing components need a line in `save.ts` `normalizeLoadedState` (breaking change: bump `STATE_VERSION`).
